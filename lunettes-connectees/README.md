# La fabrique de lunettes connectées

> Système distribué pour commander des lunettes, piloter leur fabrication et vérifier les numéros de série, avec une communication par événements.

| | |
|---|---|
| **Cadre** | Master 1 MIAGE, IDMC – Université de Lorraine |
| **Période** | 2025 – 2026 |
| **Équipe** | Projet de groupe |

## Ce qui a été réalisé

- Client JavaFX : catalogue, commande, suivi de fabrication, vérification de numéro de série
- Backend découpé en serveur et usine, échanges asynchrones sur un bus MQTT
- Production de plusieurs commandes en parallèle, configuration externalisée, publication par GitHub Actions

## Technologies et méthodes

`Java` · `JavaFX` · `MQTT` · `Maven` · `GitHub Actions`
