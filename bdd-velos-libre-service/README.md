# Base de données de vélos en libre-service

> Conception complète de la base d'un service de vélos électriques : stations, vélos, utilisateurs, abonnements et trajets.

| | |
|---|---|
| **Cadre** | Licence 3 MIAGE, IDMC – Université de Lorraine |
| **Période** | 2024 – 2025 |
| **Équipe** | Équipe de 3 |

## Ce qui a été réalisé

- Modèle UML avec classes associatives et héritage, puis modèles logique et physique
- Script SQL : tables, contraintes, jeu de données et index
- Utilisateurs et droits (GRANT), requêtes d'interrogation

## Technologies et méthodes

`SQL` · `UML` · `Modélisation` · `Index`
