# Prédiction météo par machine learning

> Deux cas : les jours de pluie à Seattle (2012 – 2015) et les canicules à Séoul.

| | |
|---|---|
| **Cadre** | Master 1 MIAGE, IDMC – Université de Lorraine |
| **Période** | 2025 – 2026 |
| **Équipe** | Équipe de 3 |

## Ce qui a été réalisé

- Analyse exploratoire : distributions, saisonnalité, matrice de corrélation
- Création de la variable cible et de variables temporelles, suppression des fuites de données
- Random Forest sur Séoul : découpage 70 / 30, évaluation par matrice de confusion, précision et rappel

## Technologies et méthodes

`Python` · `pandas` · `Random Forest` · `Arbre de décision`
