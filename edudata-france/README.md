# IDMC – ÉduData France

> Plateforme web d'analyse des inégalités scolaires : résultats du bac 2021 – 2024 croisés avec l'indice de position sociale (IPS) d'environ 7 200 lycées, à partir de l'Open Data du ministère.

| | |
|---|---|
| **Cadre** | Master 1 MIAGE, IDMC – Université de Lorraine |
| **Période** | 2025 – 2026 |
| **Équipe** | Équipe de 5 |
| **Mon rôle** | Co-responsable du design et du développement frontend. |

## Ce qui a été réalisé

- Maquettes Figma puis frontend en HTML, CSS et JavaScript sans framework
- Carte interactive de France (Leaflet), graphiques Chart.js et comparateur d'académies
- Espace administrateur sécurisé : import, nettoyage et fusion des jeux de données
- Backend FastAPI, PostgreSQL et SQLAlchemy, authentification JWT, tests pytest

## Technologies et méthodes

`JavaScript` · `Chart.js` · `Leaflet` · `Figma` · `FastAPI` · `PostgreSQL` · `UML`
