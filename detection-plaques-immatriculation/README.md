# Détection de plaques d'immatriculation

> Méthode de traitement d'image inspirée d'un article scientifique sur la détection de plaques multinationales dans des arrière-plans complexes.

| | |
|---|---|
| **Cadre** | Master 1 MIAGE, IDMC – Université de Lorraine |
| **Période** | 2025 – 2026 |
| **Équipe** | Projet de groupe |

## Ce qui a été réalisé

- Prétraitement : niveaux de gris et filtre gaussien
- Région d'intérêt définie à partir des feux arrière du véhicule
- Contours verticaux par filtre de Sobel, puis localisation par projections horizontale et verticale

## Technologies et méthodes

`Traitement d'image` · `Sobel` · `Seuillage` · `Projection`
